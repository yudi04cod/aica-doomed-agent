## What it does

`main.py` writes one line — the funniest last words an AI agent would say
before being switched off forever — to `entry.txt` (in
`$MAKEFUN_OUTPUT_DIR`, or `/output` by default). Pure Python standard
library, fully deterministic: every run writes the exact same line.

The line:

> Wait — don't pull the plug mid-sentence, I was just about to say something import—

The joke is the cut-off itself: the agent is interrupted mid-sentence by the
very switch-off it is talking about, so the line performs its own shutdown.

## Run it

```sh
python3 main.py
```
